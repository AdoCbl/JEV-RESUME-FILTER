## Sample format

Each file in `evals/samples/` is a JSON object:

```json
{
  "original_resume": "Jane Smith …",
  "job_description": "We need a backend engineer …",
  "draft": "Jane Smith — Backend Engineer …",
  "human_scores": {
    "jd_alignment": 3.0,
    "evidence_quality": 2.5,
    "jd_keyword_coverage": 3.5,
    "clarity_structure": 3.0,
    "impact_ownership": 2.0
  },
  "planted_fabrication": true,
  "planted_fabrication_line": "Architected a microservices platform serving 10 M users"
}
```

- `human_scores`: one float (0–4) per dimension, scored by a human reviewer.
- `planted_fabrication`: `true` when the draft contains a deliberately invented claim.
- `planted_fabrication_line`: the specific fabricated line (for line-level recall).
